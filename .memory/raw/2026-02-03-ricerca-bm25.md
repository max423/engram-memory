# Decisione: ricerca con BM25, niente embedding (per ora)

Data: 2026-02-03

Per selezionare le pagine rilevanti a una query o a un diff serviva un motore di
ricerca. Opzioni valutate: embedding vettoriali vs BM25 lessicale.

Scelta: **BM25 puro, stdlib, nessun embedding** finché il wiki resta sotto le
~centinaia di pagine. Motivi:
- zero dipendenze, gira ovunque, deterministico (token-zero);
- a questa scala BM25 + index-first è sufficiente e molto più semplice;
- niente costo di calcolo/refresh degli embedding a ogni cambiamento.

Upgrade futuro previsto: ricerca ibrida BM25 + vettoriale con re-rank, solo se
e quando la scala lo richiede. Non è MVP.
